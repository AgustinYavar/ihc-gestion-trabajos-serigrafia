# Gestión de trabajos para un taller de serigrafía e impresión

Proyecto de la asignatura Interacción Humano Computador (Unidad 2),
Universidad Mayor.

## Problema
La dueña de un taller de serigrafía e impresión gestiona pedidos,
cotizaciones, aprobaciones y cobros por varios chats de WhatsApp y
correos, sin un registro central. Esto genera olvidos de trabajos y
falta de visibilidad de plazos y deudas.

## Solución propuesta
Aplicación de gestión (celular y notebook) con tablero de trabajos,
panel "Hoy", control de cobros y mensajes listos para enviar por
WhatsApp o correo.
